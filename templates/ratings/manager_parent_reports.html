Parents

Parent reports

Every Sunday at 19:00 parents get a report in Telegram for each child: attendance, homework, the teacher's grades and comments, practice tests and mistakes fixed. A parent subscribes by sharing their phone in the bot; it must be the number written in Hollihop, otherwise they add the child with the family access code.

{% if not bot_enabled %}

The parents' bot is not set up yet

  1. In Telegram open @BotFather → /newbot, name it e.g. “MakonBook Parents”, username e.g. MakonBookParentsBot.
  2. Add to the server .env: TELEGRAM_PARENT_BOT_TOKEN=… and TELEGRAM_PARENT_BOT_USERNAME=MakonBookParentsBot.
  3. Run sudo makonbook up. The bot starts with the staff bot; reports go out on Sunday at 19:00.
