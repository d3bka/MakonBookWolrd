# MakonBook Structured PDF v2

Use this contract when converting an original SAT / Placement / custom test with an external AI before uploading it to MakonBook.

## Goal

Create a deterministic transport PDF. MakonBook will parse selectable marker text locally with PyMuPDF. It will NOT use AI to guess where questions, tables, graphs, or answer choices begin and end.

Produce two separate PDF files when both sections exist:
- EBRW.pdf with [[SECTION:EBRW]]
- Math.pdf with [[SECTION:MATH]]

Question counts are dynamic. Never force 27/27 or 22/22. Preserve exactly the questions that exist in the source.

## Absolute fidelity rules

1. Do not rewrite, simplify, translate, solve differently, or invent content.
2. Preserve wording, passages, answer choices, math notation, correct answers, and explanations exactly as supported by the source.
3. Do not invent an answer or explanation if the source does not contain one.
4. Every machine marker must be selectable text on its own line and written exactly as shown.
5. Never rasterize the marker text.
6. Tables, charts, scatterplots, diagrams, maps, geometry figures, coordinate planes, and other necessary visuals MUST remain visual objects. Do not flatten their data into a line of OCR text.
7. Prefer a CLEAN VECTOR RECONSTRUCTION on a pure white background. Rebuild the visual faithfully from the source data/labels/geometry using vector text, lines, shapes, axes, and paths. Preserve every value, label, scale, tick, angle, point, and relative position that is required to answer the question. Never invent missing visual information.
8. The transport visual must contain ONLY the academic visual itself. Do not include the question number, prompt, answer choices, selected-answer highlight, website chrome, logo, watermark, page number, or unrelated surrounding content. Do not retouch a screenshot to hide those artifacts; recreate the academic visual cleanly when the source supports an exact reconstruction.
9. Keep reconstructed visual content as vector objects in the PDF whenever possible. MakonBook will preserve the marker region as a white-background SVG. If exact vector reconstruction is not possible without uncertainty, use a faithful clean crop; MakonBook will keep it inside an SVG wrapper and flag it for reviewer comparison.
10. Every visual marker pair MUST be on the same PDF page. Put the visual physically between the opening and closing marker lines.


## Text fidelity profile (IMPORTANT)

The transport PDF is machine-parsed, so visual line wrapping must NOT become content. Follow these rules:

- Do not insert manual line breaks just because a sentence wraps on the source page. Ordinary prose inside PASSAGE/PROMPT/A/B/C/D must be continuous text.
- Use [[BR]] only when the source has an intentional hard line break that must remain visible.
- Use [[PAR]] for a real paragraph boundary.
- Preserve source emphasis with [[EM]]...[[/EM]].
- Preserve source underlining with [[U]]...[[/U]]. This is especially important for SAT questions that ask about an underlined claim or phrase.
- For a fill-in-the-blank line, write [[BLANK]] exactly once. Do NOT write underscores plus the word "blank" (for example, never output "______ blank"). MakonBook renders [[BLANK]] as the SAT-style blank.
- Never use HTML tags in the transport PDF.

Example:
[[PASSAGE]]
High-speed rail ... [[U]]The researchers claim that this survey reveals that there is strong support for building more HSR lines in the United States.[[/U]]
[[/PASSAGE]]

Example fill-in-the-blank:
[[PASSAGE]]
The realists rejected a romantic style that instead [[BLANK]] their subjects' positive traits.
[[/PASSAGE]]

## Math / KaTeX fidelity profile (IMPORTANT)

All mathematical notation that is not part of a visual MUST be emitted as LaTeX for KaTeX rendering. Do not approximate typeset math with Unicode superscripts, plain slash fractions, or flattened OCR order when exact notation can be read from the source.

- Inline math: \( ... \)
- Display math / standalone equation: \[ ... \]
- Fractions: \frac{a}{b}
- Roots: \sqrt{x} and \sqrt[n]{x}
- Powers: x^{2}, x^{-9}
- Subscripts: a_{1}
- Inequalities: \le, \ge, <, >
- Multiplication: \times when the source shows a multiplication sign
- Greek letters: \pi, \theta, etc.

Examples:
- Source: v⁴ - 450v³  ->  \(v^{4} - 450v^{3}\)
- Source: seventh root of p^5 divided by square root of p^(t+3)  ->  \(\frac{\sqrt[7]{p^{5}}}{\sqrt{p^{t+3}}}\)
- A system of equations should be preserved as a display block, for example:
  \[\begin{aligned} y &= -15x + 19 \\ y &= -20x + 24 \end{aligned}\]

Do not put ordinary English prose inside math delimiters. Keep punctuation outside the delimiters unless it is mathematically meaningful.

## Question category (every test)

Every question carries its official SAT domain and skill, right after [[TYPE:...]]:
[[DOMAIN:Algebra]]
[[SKILL:Linear functions]]

- Copy the domain and skill from the source when it names them. Otherwise decide them from the question itself.
- Spell them exactly as in the list below; MakonBook groups students' mistakes and topic practice by these names.
- Reading & Writing questions use a Reading & Writing domain; Math questions use a Math domain.
- If you really cannot tell, leave both markers out. MakonBook's AI check will suggest a category for a person to approve.

Reading & Writing:
- Information and Ideas: Central Ideas and Details; Command of Evidence; Inferences
- Craft and Structure: Words in Context; Text Structure and Purpose; Cross-Text Connections
- Expression of Ideas: Rhetorical Synthesis; Transitions
- Standard English Conventions: Boundaries; Form, Structure, and Sense
Math:
- Algebra: Linear equations in one variable; Linear functions; Linear equations in two variables; Systems of two linear equations in two variables; Linear inequalities in one or two variables
- Advanced Math: Nonlinear functions; Nonlinear equations in one variable and systems of equations in two variables; Equivalent expressions
- Problem-Solving and Data Analysis: Ratios, rates, proportional relationships, and units; Percentages; One-variable data: Distributions and measures of center and spread; Two-variable data: Models and scatterplots; Probability and conditional probability; Inference from sample statistics and margin of error; Evaluating statistical claims: Observational studies and experiments
- Geometry and Trigonometry: Area and volume; Lines, angles, and triangles; Right triangles and trigonometry; Circles

Put the visual inside PASSAGE or PROMPT where it logically belongs. Use [[VISUAL:QUESTION]] for the normal single main visual. If a question truly needs multiple separate visuals, use numeric labels such as [[VISUAL:1]], [[VISUAL:2]], etc. MakonBook will combine multiple main visuals vertically into one question image.

## Written answer checked by AI (Reading & Writing only)

Use this when the student writes a sentence or a short text instead of choosing A-D: rewrite a sentence, correct a mistake, combine sentences, transform to reported speech, passive voice, conditionals, and so on. MakonBook compares the student's answer with the model answer and the accepted variants first; anything else is graded by AI using the criteria. Never use it for Math.

[[QUESTION:1]]
[[TYPE:WRITTEN]]
[[LEVEL:FOUNDATION]]
[[SKILL:Past perfect]]
[[PASSAGE]]
Task instruction and the sentence the student works with, exactly as in the source.
[[/PASSAGE]]
[[PROMPT]]
The question line, if the source has a separate one.
[[/PROMPT]]
[[A]][[/A]]
[[B]][[/B]]
[[C]][[/C]]
[[D]][[/D]]
[[ANSWER]]
The model answer from the source answer key.
[[/ANSWER]]
[[ACCEPTED]]
Other fully correct answers from the source key [[OR]] another correct variant
[[/ACCEPTED]]
[[CRITERIA]]
What a correct answer must contain, from the source rubric. Example: Uses had + past participle for the earlier action; keeps the original meaning.
[[/CRITERIA]]
[[EXPLANATION]]
Explanation from the source, if available.
[[/EXPLANATION]]
[[END_QUESTION]]

Rules for written answers:
- [[ANSWER]] holds one model answer. Put every other answer the source accepts into [[ACCEPTED]], separated by [[OR]]. Leave [[ACCEPTED]] empty when the source gives only one answer.
- [[CRITERIA]] restates the source's grading rule or rubric for this item. If the source has no rubric, write the grammar point being tested in one short sentence (this is the only place where you may summarise instead of copy). Do not make the criteria stricter or looser than the source.
- Keep [[A]]..[[D]] empty.

## Placement level and skill (placement tests)

Placement tests often group questions by level and skill. Copy them from the source; do not guess:
- [[LEVEL:FOUNDATION]], [[LEVEL:PRE_SAT]] or [[LEVEL:SAT]] — the level the source assigns to the question (for example "Tier 1 / Foundation", "Tier 2 / Pre-SAT", "Tier 3 / SAT").
- [[SKILL:Name]] — the skill or topic the source names for the question, for example [[SKILL:Reported speech]] or [[SKILL:Transitions]]. Keep it short (under 120 characters) and on one line.
Both markers go right after [[TYPE:...]] and work for multiple-choice and written questions. If the source has no levels or skills, leave the markers out. MakonBook uses the levels to recommend a course and the skills to show the student a diagnostic.

If the source repeats the same question twice (for example a second copy with shuffled options), include it once and tell the human operator outside the PDF.

## Final verification before returning the PDFs

- Every [[QUESTION:n]] has exactly one [[END_QUESTION]].
- Every opened PASSAGE/PROMPT/A/B/C/D/ANSWER/EXPLANATION field has its closing tag.
- Every [[VISUAL:X]] has a matching [[/VISUAL:X]] on the same page.
- Visual regions contain only the required academic visual, not a screenshot of the whole question.
- Visuals use a pure white background and vector objects whenever exact reconstruction is possible. No watermark/logo/question UI is included in the reconstructed visual.
- No required table/graph/diagram has been converted into flattened OCR text.
- The correct answer is copied exactly from the source answer key.
- Ordinary PDF wrapping has not been converted into extra newlines. Use [[BR]] / [[PAR]] only for intentional structure.
- Underlined source text is wrapped in [[U]]...[[/U]]; emphasized source text uses [[EM]]...[[/EM]].
- Fill-in-the-blank locations use [[BLANK]], never underscores followed by the literal word "blank".
- Non-visual math is valid KaTeX-compatible LaTeX inside \( ... \) or \[ ... \].
- Empty/missing source questions are NOT invented. Preserve the gap and flag it to the human operator outside the PDF if needed.
- Written-answer questions use [[TYPE:WRITTEN]] with a model answer in [[ANSWER]], extra correct answers in [[ACCEPTED]] separated by [[OR]], and the rubric in [[CRITERIA]].
- Every question has [[DOMAIN:...]] and [[SKILL:...]] spelled exactly as in the official list (or both left out when truly unclear).
- Placement tests have [[TEST_TYPE:PLACEMENT]] in the header, and every question carries the [[LEVEL:...]] and [[SKILL:...]] that the source gives it.

## Alternative for text-only tests: JSON

If a test has no tables, graphs or pictures that must stay visual (simple pipe tables are fine), you may return one JSON file instead of PDFs. Upload it in MakonBook under Import Center -> Import a test -> Import from JSON. It goes through the same AI answer check and review.

Text uses the MakonBook format: a blank line starts a new paragraph, and a table is written as pipe rows:
| Year | Visitors |
| 2019 | 1,200 |

{
  "name": "English Placement Test (Spring 2027)",
  "test_type": "placement",
  "english": [
    {"module": 1, "number": 1, "response_type": "ai_written",
     "passage": "Rewrite the sentence using the past perfect: We arrived at the station. The train left.",
     "question": "",
     "answer": "When we arrived at the station, the train had already left.",
     "accepted_answers": ["The train had left before we arrived at the station."],
     "grading_criteria": "Uses had + past participle for the earlier action; keeps the meaning.",
     "tier": "foundation", "domain": "Standard English Conventions", "skill": "Past perfect", "explanation": ""},
    {"module": 1, "number": 2, "response_type": "multiple_choice",
     "passage": "...", "question": "Which choice completes the text?",
     "choices": {"A": "...", "B": "...", "C": "...", "D": "..."},
     "answer": "C", "tier": "pre_sat", "domain": "Expression of Ideas", "skill": "Transitions", "explanation": ""}
  ],
  "math": [
    {"module": 1, "number": 1, "question": "If \\(3x + 5 = 20\\), what is the value of \\(x\\)?",
     "choices": {"A": "3", "B": "5", "C": "15", "D": "25"}, "answer": "B",
     "domain": "Algebra", "skill": "Linear equations in one variable", "explanation": ""}
  ]
}

- test_type: "regular" (practice test), "placement" or "event".
- response_type: "multiple_choice", "open_text" (exact short answer) or "ai_written" (sentence checked by AI).
- tier: "foundation", "pre_sat", "sat" or "" when the source has no levels.
- domain / skill: the official SAT domain and skill from the list above ("" when truly unclear).
- The same fidelity rules apply: copy wording and answers exactly, never invent content.
