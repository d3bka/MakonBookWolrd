# Премиум-контент Admissions (V81–V82): как загрузить видео и PDF SATMakon

Видео и PDF из папки **Lessons** — платный контент SATMakon. Правила:

- **Никогда** не класть их в git, в `static/`, в `/app/media` или в **старый** R2-бакет. У старого бакета включён публичный домен `r2.dev`, через него любой объект можно скачать.
- Видео хранятся только как зашифрованные куски HLS (AES-128). Исходные mp4 после импорта удаляются.
- Ключ шифрования лежит только в базе и выдаётся только ученику, у которого есть доступ к уроку. В R2, файлах или логах ключа нет.
- Куски видео лежат **либо** в отдельном **приватном** R2-бакете (рекомендуется, V82), **либо**, пока он не подключён, в приватном Docker-томе `makonbook_premium_content` (`/premium`).
- PDF хранятся только как картинки страниц: в приватном R2 (V86, при загрузке с компьютера) или на сервере. Каждая страница при показе получает водяной знак с именем, логином, ID, частью телефона ученика и датой. Сам PDF сайт не отдаёт никогда.

## Как устроена защита

| Что | Как защищено |
|---|---|
| Доступ | Только залогиненный ученик. Уроки 1–3 открыты всем ученикам, остальные — только текущим ученикам SATMakon (Hollihop). PDF открыт не-ученику, только если все его уроки бесплатные. Сотрудники и гости ничего не получают. |
| Ссылки | Каждый запрос (плейлист, ключ, кусок видео, страница PDF) несёт подписанный токен. Токен живёт 2 часа и привязан к ученику, к уроку или файлу и к сессии входа. Доступ перепроверяется каждые 2 минуты. Пересланная ссылка не работает ни у кого другого. |
| Приватный R2 (V82) | Плеер всегда спрашивает кусок у Django. Django проверяет всё (вход, доступ, токен, устройство, лимиты) и только потом отвечает редиректом на подписанную ссылку R2, которая живёт **60 секунд**. Публичного доступа к бакету нет. CORS разрешает только makonbook.uz. |
| Сервер (без R2) | nginx отдаёт `/premium` только через `internal`-location `/_premium/` и только после проверки в Django (`X-Accel-Redirect`). Прямой URL — 404. |
| Устройства (V82) | Премиум-контент играет максимум на **2 устройствах** одного ученика. Открыл урок на третьем — самое старое отключается. Ученик видит сообщение «аккаунт открыт на другом устройстве», переоткрытие страницы возвращает доступ этому устройству. |
| Лог ключей (V82) | Каждая выдача ключа записывается: кто, какое видео, IP, браузер, время. Admin → Admissions key log. Ключи к **25+ разным видео за час** не выдаются (429). Ключи на **3+ разных IP за сутки** дают предупреждение в лог `makonbook.premium`. |
| Видео | Зашифрованный HLS, а не mp4. Нет кнопки «скачать», нет картинки-в-картинке и трансляции, отключено контекстное меню. |
| Водяной знак | Имя · логин · ID · `+99890•••••12` плавает поверх видео, в том числе в полноэкранном режиме. На iPhone вместо нативного полного экрана используется CSS-полноэкранный, чтобы знак не пропадал. Если знак удалить или скрыть через DevTools, видео встаёт на паузу, а знак возвращается. |
| PDF | Только картинки страниц с водяным знаком. Отключены сохранение, печать (Ctrl+S/Ctrl+P), выделение и перетаскивание. |
| Массовое скачивание | Лимиты на пользователя: за 10 минут 300 кусков видео (~50 минут просмотра), 60 ключей, 200 страниц; за день 2500 кусков (~7 часов видео) и 1500 страниц. Дальше сервер отвечает 429. |
| Кэш, другие сайты | Все ответы `private, no-store`, `noindex`. Запросы с чужих сайтов отклоняются. |

Записать экран технически не может запретить ни один сайт. Для этого и нужен водяной знак: по нему видно, чей аккаунт слил запись.

## Шаг 0 (один раз). Создать приватный R2-бакет

Это делает владелец аккаунта Cloudflare:

1. Cloudflare → **R2** → **Create bucket**, например `makonbook-premium`.
2. **Public access не включать**: ни `r2.dev`, ни Custom Domain.
3. R2 → **Manage API tokens** → **Create API token**:
   - права **Object Read & Write**;
   - область **только этот бакет**;
   - сохранить **Access Key ID**, **Secret Access Key** и **S3 endpoint** (`https://<ACCOUNT_ID>.r2.cloudflarestorage.com`).
4. Добавить в `.env` на сервере (не в git):
   ```
   MAKONBOOK_PREMIUM_R2_BUCKET=makonbook-premium
   MAKONBOOK_PREMIUM_R2_ENDPOINT_URL=https://<ACCOUNT_ID>.r2.cloudflarestorage.com
   MAKONBOOK_PREMIUM_R2_ACCESS_KEY_ID=...
   MAKONBOOK_PREMIUM_R2_SECRET_ACCESS_KEY=...
   ```
   Необязательные настройки (значения по умолчанию в скобках):
   - `MAKONBOOK_PREMIUM_R2_URL_TTL` (60) — сколько секунд живёт ссылка на кусок;
   - `MAKONBOOK_PREMIUM_MAX_DEVICES` (2) — сколько устройств может смотреть одновременно;
   - `MAKONBOOK_PREMIUM_MAX_VIDEOS_PER_HOUR` (25) — ключи к скольким разным видео можно получить за час.
5. Перезапустить стек и проверить бакет, затем выставить CORS:
   ```bash
   docker compose up -d
   docker exec makonbook-web python manage.py push_admissions_media_to_r2 --check
   docker exec makonbook-web python manage.py push_admissions_media_to_r2 --cors
   ```
   Команда откажется работать, если указан старый публичный бакет.

Без шага 0 всё тоже работает: куски видео раздаёт сервер из приватного тома.

## Загрузка с компьютера (V86, рекомендуется)

Видео и PDF не копируются на сервер. Команда на компьютере сама:

1. шифрует каждый `Lesson N - ....mp4` (AES-128 HLS) во временной папке;
2. заливает **только зашифрованные куски** в приватный R2-бакет;
3. отправляет сайту по HTTPS номер урока, ключ и плейлист (защищённый API, токен из `.env`);
4. удаляет временную папку. Исходный mp4 на компьютере только читается.

PDF из списка курса превращаются в картинки страниц и тоже уходят в приватный R2. Водяной знак сайт ставит на каждую страницу в момент показа, поэтому чистая страница никогда не уходит к ученику.

**Один раз:**

1. Придумать токен: `python -c "import secrets; print(secrets.token_urlsafe(48))"`.
2. На сервере добавить в `.env` строку `MAKONBOOK_MEDIA_UPLOAD_TOKEN=<токен>` и перезапустить: `docker compose up -d`.
3. На компьютере в `.env` проекта:
   - `MAKONBOOK_MEDIA_UPLOAD_TOKEN=<тот же токен>`;
   - `MAKONBOOK_MEDIA_UPLOAD_SITE=https://makonbook.uz`;
   - `MAKONBOOK_PREMIUM_R2_*` — тот же приватный бакет, что и на сайте (команда проверит).
4. ffmpeg: `.venv\Scripts\pip install imageio-ffmpeg` (или установленный ffmpeg в PATH).

**Каждый раз:**

```powershell
.venv\Scripts\python manage.py upload_admissions_media "C:\Users\turgu\OneDrive\Desktop\Lessons" --dry-run   # что будет загружено
.venv\Scripts\python manage.py upload_admissions_media "C:\Users\turgu\OneDrive\Desktop\Lessons"             # загрузить новое
.venv\Scripts\python manage.py upload_admissions_media "C:\Users\turgu\OneDrive\Desktop\Lessons" --only 7 --force   # заменить урок 7
```

- Уже загруженные уроки и файлы пропускаются. Повторный запуск докачивает то, что упало.
- `--videos-only` / `--docs-only` — только видео или только PDF.
- Если сайт отказал (например, кусков в R2 меньше, чем в плейлисте), залитое удаляется из R2. Если пропала связь в момент регистрации, залитое остаётся: проверьте урок на сайте и запустите команду снова.
- Новый PDF сначала добавляется в список курса (`apps/sat/admissions_course.py`, DOCUMENTS) и деплоится, иначе команда его пропустит.

## Загрузка через сервер (старый способ, V81–V82)

1. Задеплоить код и перезапустить стек:
   ```bash
   cd /opt/sat-makon/makonbook
   docker compose pull && docker compose up -d
   ```
   Миграции 0072–0074 применятся сами.

2. Скопировать папку **Lessons** со своего компьютера на сервер по SSH (только к себе на сервер, никуда больше):
   ```bash
   scp -r "C:\Users\turgu\OneDrive\Desktop\Lessons" root@<сервер>:/root/lessons-incoming
   ```

3. Положить её в приватный том и запустить импорт:
   ```bash
   docker cp /root/lessons-incoming makonbook-web:/premium/incoming
   docker exec makonbook-web python manage.py import_admissions_media /premium/incoming
   ```
   Видео нарезаются без перекодирования, это несколько минут на всю папку.
   - Если шаг 0 сделан, зашифрованные куски сразу уходят в приватный R2 и удаляются с сервера.
   - Если нет, куски остаются в томе.
   - PDF остаются на сервере как картинки страниц (перенести в R2: `push_admissions_media_to_r2`).

4. **Удалить исходники** — и в томе, и на сервере:
   ```bash
   docker exec makonbook-web rm -rf /premium/incoming
   rm -rf /root/lessons-incoming
   ```

5. Проверить:
   - `curl -I https://makonbook.uz/_premium/` → **404**;
   - под учеником Admissions → урок 1: видео играет, поверх видны имя и часть телефона;
   - под не-учеником SATMakon урок 4 закрыт замком;
   - Admin → Admissions key log: появилась запись о выдаче ключа.

Если R2 подключили позже, перенести уже импортированные видео и страницы PDF с сервера в бакет:
```bash
docker exec makonbook-web python manage.py push_admissions_media_to_r2
```

## Дальше

- **Заменить одно видео:** с компьютера `upload_admissions_media <папка> --only N --force` (или на сервере `import_admissions_media /premium/incoming --only N --force`). Старые куски удаляются и с сервера, и из R2.
- **Отключить устройство ученика сразу:** Admin → Admissions device sessions → выбрать → «Switch off the selected devices».
- **Название, описание, к каким урокам привязан PDF** (это же определяет, кто его видит): Admin → Admissions files (premium).
- **Тексты уроков, конспекты, ссылки:** Admin → Admissions lessons.
- **YouTube-ссылки:** у платных уроков поле YouTube URL должно оставаться пустым — иначе урок покажет публичное YouTube-видео.
- **Резервные копии:** том `makonbook_premium_content` и приватный бакет бэкапить только в приватное хранилище.
- **Скрипт `upload_videos_to_r2.py` от другого разработчика не нужен.** Он кладёт ключи в файл `keys.csv` на компьютере и рассчитан на Cloudflare Worker. Наша команда импорта делает то же самое на сервере, а ключи сразу попадают в базу.
