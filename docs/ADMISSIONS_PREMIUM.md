# Премиум-контент Admissions (V81): как загрузить видео и PDF SATMakon

Видео и PDF из папки **Lessons** — платный контент SATMakon. Правила:

- **Никогда** не класть их в git, в `static/`, в `/app/media` или в R2: у R2-бакета включён публичный домен `r2.dev`, и любой объект там можно скачать.
- Файлы живут только в приватном Docker-томе `makonbook_premium_content`, который смонтирован в `/premium`.
- Видео хранятся только как зашифрованные куски HLS (AES-128). Исходные mp4 после импорта удаляются.
- Ключ шифрования лежит только в базе и выдаётся только ученику, у которого есть доступ к уроку.
- PDF на сервере хранятся только как картинки страниц. Каждая страница при показе получает водяной знак с именем, логином, ID ученика и датой. Сам PDF сайт не отдаёт никогда.

## Как устроена защита

| Что | Как защищено |
|---|---|
| Доступ | Только залогиненный ученик. Уроки 1–3 открыты всем ученикам, остальные — только текущим ученикам SATMakon (Hollihop). PDF открыт не-ученику, только если все его уроки бесплатные. Сотрудники и гости ничего не получают. |
| Ссылки | У каждого запроса (плейлист, ключ, кусок видео, страница PDF) есть подписанный токен. Он живёт 2 часа и привязан к ученику, уроку или файлу и к сессии входа. Доступ перепроверяется каждые 2 минуты: ученик, который ушёл из SATMakon, теряет видео и файлы почти сразу. Пересланная ссылка не работает ни у кого другого и даже у того же ученика в другом браузере. |
| Файлы на диске | nginx отдаёт `/premium` только через `internal`-location `/_premium/` — и только когда Django ответил `X-Accel-Redirect` после проверки доступа. Прямой URL на файл — 404. |
| Видео | Зашифрованный HLS, а не mp4. Нет кнопки «скачать», нет картинки-в-картинке и трансляции, отключено контекстное меню. Поверх видео плавает имя ученика, в том числе в полноэкранном режиме. |
| PDF | Только картинки страниц с водяным знаком. Отключены сохранение, печать (Ctrl+S/Ctrl+P), выделение и перетаскивание. |
| Массовое скачивание | Лимиты на пользователя: за 10 минут 300 кусков видео (~50 минут просмотра), 60 ключей, 200 страниц; за день 2500 кусков (~7 часов видео) и 1500 страниц. Дальше сервер отвечает 429. |
| Другие сайты | Запросы с чужих сайтов (`Sec-Fetch-Site: cross-site`) отклоняются. |
| Кэш | Все ответы `private, no-store`, `noindex`. Браузеры и прокси ничего не кэшируют. |
| Аудит | В лог `makonbook.premium` пишется, кто открыл какое видео и файл, а также срабатывания лимитов. |

Записать экран технически не может запретить ни один сайт. Для этого и нужен водяной знак: по нему видно, чей аккаунт слил запись.

## Загрузка на сервер (один раз)

1. Задеплоить код V81 (новый образ) и перезапустить стек:
   ```bash
   cd /opt/sat-makon/makonbook
   docker compose pull && docker compose up -d
   ```
   Миграции 0072–0073 применятся сами (`RUN_MIGRATIONS=1`). Создастся том `premium_content`, nginx получит новый конфиг.

2. Скопировать папку **Lessons** со своего компьютера на сервер по SSH (только к себе на сервер, никуда больше):
   ```bash
   scp -r "C:\Users\turgu\OneDrive\Desktop\Lessons" root@<сервер>:/root/lessons-incoming
   ```

3. Положить её в приватный том и запустить импорт:
   ```bash
   docker cp /root/lessons-incoming makonbook-web:/premium/incoming
   docker exec makonbook-web python manage.py import_admissions_media /premium/incoming
   ```
   Видео нарезаются без перекодирования, это несколько минут на всю папку. Команда пишет, сколько кусков и страниц получилось.

4. **Удалить исходники** — и на сервере, и в томе:
   ```bash
   docker exec makonbook-web rm -rf /premium/incoming
   rm -rf /root/lessons-incoming
   ```

5. Проверить:
   - `curl -I https://makonbook.uz/_premium/` должен вернуть **404**;
   - под учеником открыть Admissions → урок 1: видео играет, поверх видно имя;
   - под не-учеником SATMakon урок 4 должен быть закрыт замком.

## Дальше

- **Заменить одно видео:** положить новый `Lesson N - ....mp4` в `/premium/incoming` и выполнить `import_admissions_media /premium/incoming --only N --force`.
- **Название, описание, к каким урокам привязан PDF** (это же определяет, кто его видит): Django admin → Admissions files (premium).
- **Тексты уроков, конспекты, ссылки:** Django admin → Admissions lessons.
- **YouTube-ссылки:** у платных уроков поле YouTube URL должно оставаться пустым — иначе урок покажет публичное YouTube-видео.
- **Резервные копии:** том `makonbook_premium_content` бэкапить только в приватное хранилище, никогда — в публичный R2.
